**Tools:** SQL, MySQL, Valentina Studio, Tableau, Tableau Prep

- [View Analysis Report](analytic%20report.pdf)

Two part data analysis project completed for Data Management Fundamentals at Carnegie Mellon University.

## BikeShare Analysis

Analyzed BikeShare trip data across Los Angeles, Austin, Pittsburgh, and Portland to compare commuting and leisure usage.

I developed a rule based classification for identifying likely commuting trips using trip timing, duration, day of week, and station information. I then used SQL to aggregate and compare trip behavior across the four metro areas.

**Key finding:** Estimated commute share ranged from 13.4% in Portland to 24.8% in Los Angeles.

## Pennsylvania Demographics Analysis

Analyzed Pennsylvania population data from 2011–2021 to compare population change across counties with different population densities.

I aggregated ZIP level demographic and geographic data to the county level, calculated population density and percentage population change, and classified counties as dense, moderate, or sparse.

**Key finding:** Dense counties grew by an average of 4.0%, while moderate counties declined by 1.4% and sparse counties declined by 5.0%.
